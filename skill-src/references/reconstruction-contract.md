# 重建契约

编写六平面任务束时必须遵守以下全部规则。这些是源数据要求，不是渲染器启发式规则。

## 表达方式

- 将可编辑文字、形状、路径、连接线、边框、填充、表格、列表和简单图标重建为语义节点。
- 禁止擦除源文字后把剩余页面作为背景图。拒绝整页、近整页或源图派生复合位图代理。
- image 节点只用于原始照片、纹理、品牌标识或复杂插画。按要求声明 `imageUsage.contentKind`、`derivation`、`textRemoved` 和 `sourceRegion`。源图裁切不属于可编辑简单图标。
- 未知语义使用带可见可编辑子节点的递归 `custom` 节点。`custom` 不是位图降级通道。

## 文字

- 精确保留字符和源图换行。不得引入源图不存在的换行，不得用空格或制表符进行布局。
- 将完整字符串划分为 run。保留每段文字的字体族、字号、字重、样式、颜色、透明度、字距、字偶距和基线偏移。
- 有测量结果时，显式记录字素边界、视觉行、基线、行高、段落间距、内边距、advance 和定位簇。
- 从源图像素和渲染校准结果测量排版，不得只依据字符数量、平均字宽公式或 OCR 框宽度推算。
- 在与文字节点相同的坐标空间记录可见字形并集 `inkBox` 和 `boundaryPolicy.minimumClearance`。
- 应用内边距和边框对齐后，受保护文字墨迹必须位于自身及所有祖先内容框内。除非明确将对应边缘 Observation ID 加入允许列表，否则文字不得与边缘 Observation 重叠。

## 布局与结构

- 使用一棵递归树表达盒子、分组、行、单元格、列表项、卡片、图标文字组合和重复组件。所有解析后的框均使用源图像素。
- 图标和文字必须作为同一归属分组下的兄弟节点。每个简单图标都要有紧贴可见内容的边界和可编辑 path/group 子节点；只有源内容本身是栅格图，或复杂到无法忠实矢量重建时，才使用 image 节点。图标和文字不得共用或重叠同一文字框。
- 显式记录内边距、外边距、重复间隔、对齐和邻接关系。渲染器不得自动分配间距、自动对齐、自动换行或重新计算布局。
- 分别保存四条边框和四个圆角。保留边框宽度、颜色、透明度、样式、对齐方式、绘制顺序及其后的容器填充。
- 用渐变类型、角度、有序色标、偏移、颜色和透明度表达渐变填充。禁止用平均纯色替代已测量渐变。

## 观测与归属

- 分别为文字、图标、图片、形状、边缘、间距和采样颜色创建 Observation。不得依赖大范围通用区域掩盖缺失事实。
- 每个 Observation 必须恰好有一个 responsibility 为 `1` 的 Ownership 归属；其所有者必须能够到达一个可编辑 Render 原语。
- 将背景和局部填充描述为真实的形状或颜色证据。面板中正确的一半不得掩盖缺失或错误的另一半。

## 验证

- 将文字、简单图标、边框、形状、图片、间距和颜色作为相互独立的局部硬门槛类别。全页高分不能补偿局部区域失败。
- 修改 JSON 前，先把每个失败归类为源数据、渲染器或验证器责任。系统性同类失败，或报告与 OOXML 证据矛盾时，必须修复运行时，不得扭曲源数据。
- 禁止为了提高门槛分数而删除已测量的圆角、渐变、边框、局部颜色或间距，也不得把数值清零。禁止直接修补 PPTX 输出或降低阈值。
- 比较结构时使用有界空间容差吸收栅格化差异。填充只比较排除更高绘制顺序内容后的可见平坦像素；不得把子文字或图标计为背景颜色错误。
- 由运行时按内容摘要缓存源图分析并生成紧凑复查裁图。源图未变化的迭代必须复用这些产物，不得再次加载完整图片。
- 仅在严格源覆盖、视觉比较、对象检查以及编辑、保存、重开验证全部通过后交付。
