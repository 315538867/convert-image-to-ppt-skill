# 重建精度规则

## 验收优先级

1. 精确保留可见文字、换行和带样式 run。
2. 保留几何、间距、内边距、对齐、基线和阅读顺序。
3. 保留颜色、边框、效果、轮廓和视觉层级。
4. 在不削弱前三项要求的前提下最大化可编辑性。

不得重新设计、改写、归一化或静默简化源图。

## 源图归属覆盖

语义重建前，在 Observation Plane 中盘点源图对象。每个 Observation 必须恰好有一个 responsibility 为 `1` 的 Ownership 归属，且每个所有者都必须到达可编辑 Render 原语。全页高分不能补偿缺失的文字、形状、图标、连接线、边框、间距或颜色归属。

编译后运行本地源探测器。它从不可变源图中提取显著像素和边缘，不允许容器或背景归属覆盖无法解释的内部边缘，并要求像素覆盖率至少为 `0.98`、边缘覆盖率至少为 `0.96`。任一门槛失败时都要检查生成的覆盖图。

文字 Observation 必须包含精确文字、框边界、紧贴字形的边界、视觉行、基线、字素边界、run 和 advance。轮廓重要时，图形 Observation 应包含紧贴可见内容的边界，以及实测蒙版或轮廓。间距和颜色必须有各自的 Observation，不得由渲染器推断。

验证器直接从 Semantic Plane 派生额外受保护区域，包括文字墨迹并集、可见填充、每条可见边框、图标、图片和连接线。填充检查排除绘制顺序更高的前景框和边缘像素，避免把子文字、图标和边框误判为背景颜色错误。Observation 区域仍是源事实的必需证据，尤其是间距和采样颜色；但缺少 Observation 不能关闭语义填充、边框或文字门槛。

## 文字还原

- 要求文字证据与渲染文字内容完全一致。
- 行和 run 范围必须无缺口、无重叠地覆盖完整字符串。
- 保留源图显式换行，不依赖 PowerPoint 自动换行。
- 每个 run 都必须包含完整字体和颜色数据。
- 显式记录段落对齐、垂直对齐、行距、段落间距、内边距和换行方式。
- 为可见字形并集记录一个 `inkBox`，并记录逐边 `boundaryPolicy.minimumClearance`；二者与文字节点框使用相同坐标空间和单位。
- 声明的度量无法容纳实测行时，拒绝该文字框。
- 受保护墨迹框与自身或祖先的边框、内边距相交时拒绝；只有精确边缘 Observation 被明确列为有意重叠时例外。

## 图形与图片还原

- 分别记录提取边界、效果边界和核心主体边界。
- 将源图 `contentBounds` 映射到目标 `contentFrame`，同时保留周围 `effectBounds`。
- 使用显式蒙版，不得使用近白阈值代替。
- 检查真实蒙版通道；文件声明 Alpha 不代表 Alpha 通道实际包含透明度。
- 移除底色时清理 RGB 边缘污染。
- 除非源证据证明存在变形，否则保持宽高比。
- 图片资源保持本地且不含文字，受保护品牌标识除外。

## 验证

将预览图调整为与源图完全一致的像素尺寸。在源位置比较每个证据区域，使渲染位移产生错误，而不是通过围绕目标框裁切预览来掩盖位移。

结构比较使用模糊像素差异和搜索半径不超过两像素的对称边缘 F1。保留原始像素相似度作为诊断证据。这样可以吸收渲染器抗锯齿和一像素栅格偏移，同时拒绝三像素几何位移。

按元素类型使用不同门槛：

- text：精确内容及局部边缘、像素比较；
- graphic：蒙版权重颜色及边缘比较；
- shape：边界、填充、描边和效果比较；
- image：局部像素、边缘、裁切和蒙版比较；
- connector：端点、锚点、描边和箭头比较；
- region：组件边界、间距、对齐和局部视觉比较。

将 `color`、`spacing`、`shape` 和 `image` 视为独立质量类别。不得合并为通用区域：即使全页分数很高，缺失半块填充、边框位移或间距丢失仍必须触发局部硬门槛失败。

全页相似度只用于整体判断。对每个被引用证据项执行门槛，并按类型汇总。失败项必须指出证据 ID 和可能的错误类别，例如几何或排版、颜色透明度或效果。

配置视觉能力时，在局部验证后同时审查源图和渲染预览。重新读取精确文字，并检查换行、局部颜色、基线、裁切、蒙版、渐变、圆角、间距和重叠。所有错误或违规都视为质量门槛失败。若大量无关对象出现相同且不合理的失败模式，或报告与 OOXML 证据矛盾，必须先检查验证器，再修改 authoring 数据。

## 可编辑性

根据已选择的表达方式计算可编辑覆盖率。原生文字、形状、连接线和受支持路径计为可编辑；SVG 和栅格表达不计。`simpleIconMustBeEditable` 为 true 时，拒绝所有由位图支撑的 `icon`；复杂栅格符号必须如实表示为 `image`。拒绝把不支持的原生能力静默降级为截图。
